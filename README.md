A one-line office joke writer for make.fun's "One-Line Office Joke Laugh-Off" bounty, $3 in USDC. The program writes a single original one-line office joke to `/output/entry.txt`, where a judge model compares entries two at a time and crowns the biggest laugh.

The joke: "My calendar was so full I booked a meeting with myself just to eat lunch — and I declined it."

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. No dependencies, no network, no input. The output file holds exactly one line, 93 characters, no trailing newline.
